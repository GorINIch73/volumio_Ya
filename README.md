# Яндекс Музыка для Volumio

Проект доработки плагина Яндекс Музыки для Volumio: интерфейс, близкий по структуре к привычной Яндекс Музыке, управление с сенсорного экрана и смартфона, сохранение лайков и изменений плейлистов в аккаунте Яндекса.

Целевое устройство — Raspberry Pi 5 с небольшим сенсорным экраном и внешним USB-ЦАПом. Воспроизведением управляет Volumio; браузер телефона работает как пульт. Закрытие браузера не должно останавливать музыку.

## Статус проекта

**Сейчас в репозитории находятся описание и [план разработки](PLAN.md). Собственного установочного пакета, новой оболочки и веб-обновления пока нет.**

Основа проекта — [плагин achechulin/yandex_music](https://github.com/achechulin/volumio-plugins-sources/tree/master/yandex_music). Инструкция ниже относится именно к этому исходному плагину. Она не устанавливает запланированные доработки из данного репозитория.

| Возможность | Состояние |
| --- | --- |
| Воспроизведение Яндекс Музыки через Volumio/MPD | Реализовано в исходном плагине |
| Поиск, чтение плейлистов и «Мне нравится» | Реализовано в исходном плагине |
| «Моя волна» и события прослушивания/пропуска | Реализовано в исходном плагине; требует проверки на устройстве |
| Постановка и снятие лайка в Яндексе | Запланировано |
| Создание и редактирование плейлистов Яндекса | Запланировано |
| Адаптивный интерфейс в стиле Яндекс Музыки | Запланировано |
| Обновление через браузер, консоль логов и откат | Запланировано |

Интеграция использует неофициальный API и не является продуктом Яндекса. Совместимость с конкретной версией Volumio и актуальным API необходимо проверять. Версия Volumio на целевом устройстве пока не зафиксирована.

## Как это будет работать

```text
Сенсорный экран ─┐
                ├─ Веб-интерфейс → Плагин Яндекс Музыки → Volumio / MPD → USB-ЦАП
Смартфон ────────┘                         │
                                   Аккаунт Яндекса
```

На небольшом экране — крупная обложка, кнопки воспроизведения, лайк и «Моя волна». На телефоне — поиск, коллекция и управление плейлистами. Оба экрана управляют одной очередью воспроизведения; дублирование рабочего стола через VNC не требуется.

Локальная библиотека остаётся доступной штатными средствами Volumio. Звук и другие стриминговые сервисы не входят в первый этап этого проекта.

## Что понадобится

- Raspberry Pi с установленной и работающей Volumio; целевая платформа проекта — Pi 5.
- Аккаунт Яндекса с подпиской, позволяющей слушать Яндекс Музыку.
- Доступ Raspberry к интернету, а телефона или компьютера — к её локальной сети.
- USB-ЦАП, уже определяемый Volumio.
- SSH-доступ для первоначальной установки исходного плагина.
- Для локального управления — настроенный сенсорный экран и браузер/плагин дисплея, совместимый с установленной Volumio.

## Установка исходного плагина на Volumio

Если Яндекс Музыка уже установлена и работает, повторная установка не нужна. Перед заменой существующей сборки сохраните её код и настройки: установленный вариант может отличаться от опубликованного.

### 1. Откройте Volumio и включите SSH

Откройте `http://volumio.local` или адрес Raspberry в локальной сети, например `http://192.168.1.50`.

Перейдите на `http://volumio.local/dev` либо `http://192.168.1.50/dev` и включите SSH кнопкой **Enable**. Этот способ описан в [официальной справке Volumio](https://help.volumio.com/en/articles/13-how-do-i-enable-ssh-connection).

### 2. Подключитесь к Raspberry

В терминале компьютера выполните:

```bash
ssh volumio@volumio.local
```

Если имя не определяется, используйте IP-адрес устройства:

```bash
ssh volumio@192.168.1.50
```

Замените адрес на свой и используйте SSH-пароль устройства.

### 3. Установите плагин

Следующие команды выполняются **на Raspberry через SSH**, для новой установки:

```bash
git clone https://github.com/achechulin/volumio-plugins-sources.git
cd volumio-plugins-sources/yandex_music
volumio plugin install
```

Дождитесь сообщения об успешной установке. Если каталог уже существует, сначала выясните, какая версия в нём находится; не удаляйте его ради повторного клонирования.

Команды приведены по [инструкции автора плагина](https://github.com/achechulin/volumio-plugins-sources/tree/master/yandex_music#manual-installation). На целевой Raspberry в рамках этого проекта установка ещё не проверялась.

### 4. Включите плагин

В веб-интерфейсе Volumio откройте **Плагины → Установленные плагины → Yandex Music**, включите плагин и откройте его настройки. Названия пунктов могут отличаться в зависимости от языка и версии Volumio.

## Настройка

### Аккаунт Яндекса

В исходном плагине предусмотрены два способа входа:

1. **Пароль** — указать имя пользователя и пароль, нажать «Войти».
2. **Токен** — вставить действующий токен доступа к API Яндекс Музыки и нажать «Войти».

Наличие способа в интерфейсе не гарантирует, что он работает с текущими требованиями Яндекса. Если вход по паролю не проходит, особенно при дополнительных проверках аккаунта, можно использовать предусмотренный плагином вход по токену. Получение токена описывается в [документации неофициального клиента](https://github.com/MarshalX/yandex-music-api); сам токен не отправляйте в issues, скриншотах или логах.

После успешного входа откройте источник **Яндекс Музыка** и проверьте разделы **Мои плейлисты**, **Мне нравится** и **Моя волна**.

### USB-ЦАП и качество

1. Подключите ЦАП к Raspberry.
2. В настройках воспроизведения Volumio выберите его как устройство вывода (**Output Device**).
3. Сначала проверьте звук на локальном файле или другом работающем источнике Volumio.
4. Затем запустите трек из Яндекс Музыки.
5. В настройках плагина при необходимости включите **Высокое качество** и сохраните настройку.

Фактический формат зависит от трека, аккаунта и ответа сервиса. Переключатель высокого качества сам по себе не гарантирует FLAC для любого трека. Настройки выхода и микшера относятся к Volumio, а не к аккаунту Яндекса.

### Телефон и сенсорный экран

С телефона в той же сети откройте адрес Volumio. В исходной версии управление происходит через стандартный интерфейс Volumio.

На сенсорном экране настройте вывод этого же интерфейса средствами установленного плагина дисплея/киоска. Установка и калибровка самого экрана зависят от его модели.

Отдельный интерфейс в стиле Яндекс Музыки появится на следующем этапе; его адрес и настройка автозапуска будут добавлены после реализации.

## Обновление через веб-интерфейс — запланировано

Первый рабочий выпуск должен включать страницу **Обслуживание**. Предполагаемый порядок:

1. Получить собранный пакет обновления.
2. Загрузить его на странице обслуживания.
3. Проверить предлагаемую версию и нажать **Обновить**.
4. Дождаться проверки пакета, установки и переподключения интерфейса.
5. При проблеме скачать логи или вернуться к предыдущей версии.

Планируются сохранение настроек, автоматический откат при неудачном запуске и отдельный сервис обслуживания, доступный при сбое музыкального плагина. Обновление серверной части может прервать воспроизведение на время перезапуска Volumio.

**В текущем репозитории эта страница и механизм обновления ещё не реализованы.** Обновление из онлайн-канала без ручной загрузки файла потребует отдельной настройки публикации релизов.

## Логи и диагностика

В будущем на странице обслуживания будут поток логов, фильтры, копирование и скачивание отчёта с маскированием секретов.

До её появления логи службы можно посмотреть через SSH:

```bash
sudo journalctl -u volumio -n 200 --no-pager
```

Для наблюдения во время воспроизведения ошибки:

```bash
sudo journalctl -u volumio -f
```

Завершить просмотр — `Ctrl+C`. Сырые логи исходного плагина не проходят наше маскирование: перед публикацией удалите токены, cookies, пароли и чувствительные параметры ссылок.

При сообщении о проблеме приложите:

- версию Volumio и плагина;
- модель Raspberry и ЦАПа, а при проблеме интерфейса — разрешение экрана и браузер;
- последовательность действий, ожидаемый и фактический результат;
- очищенный фрагмент логов за время ошибки.

| Проблема | Что проверить |
| --- | --- |
| `volumio.local` не открывается | Открыть IP-адрес Raspberry; проверить подключение к одной сети |
| Нет звука из всех источников | Выбранный выход Volumio, подключение ЦАПа, громкость и mute |
| Локальные файлы играют, Яндекс — нет | Авторизацию, подписку, интернет и логи плагина |
| Лайк или плейлист не появился в Яндексе | В исходном плагине запись этих изменений не реализована |
| Плейлист показывает старые треки | Исходный плагин кэширует содержимое; обновление кэша входит в план доработки |

## Разработка и тестирование

Предусмотрены три уровня проверки:

1. **На компьютере:** интерфейс с автоматическим обновлением, фиктивные данные, проверки лайков, плейлистов и обработки ошибок.
2. **С реальным API Яндекса:** проверка авторизации и операций на отдельном тестовом плейлисте.
3. **На Raspberry:** интеграция с Volumio, реальный звук через ЦАП, сенсор, управление с телефона и обновление с откатом.

Переустановка после каждой правки не нужна. Изменения интерфейса предполагается проверять обновлением страницы, серверные изменения — доставкой новой версии и перезапуском службы. Установку пакета, обновление зависимостей и удаление проверяем отдельно перед выпуском.

Локальный стенд, сборочные команды и автоматические тесты пока не добавлены. Подробная последовательность работ — в [PLAN.md](PLAN.md).
