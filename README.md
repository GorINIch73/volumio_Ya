# Яндекс Музыка для Volumio · Media Str

Версия **0.4.0** — штатный плагин категории `music_service` для Volumio 4 (Bookworm). Управление находится в **Плагины → Установленные**, библиотека — в **Обзор → Яндекс Музыка · Media Str**, воспроизведение — в общем плеере Volumio. Этот же интерфейс доступен на сенсорном экране и телефоне.

Репозиторий: [GorINIch73/volumio_Ya](https://github.com/GorINIch73/volumio_Ya).

Реализованы вход по токену, проверка аккаунта и выход, собственные плейлисты и «Мне нравится», страницы по 50 треков, добавление отдельного трека в очередь и воспроизведение через MPD. В очереди сохраняется ID трека; свежая MP3-ссылка запрашивается перед каждым запуском. Пауза, продолжение, перемотка и переключение выполняются средствами Volumio.

**Сборка пока предназначена для разработки и проверки на устройстве.** Локальные тесты проверяют контракт плагина и обмен с Python; установку, сенсорный интерфейс, реальный аккаунт, переходы между треками и звук через ЦАП необходимо проверить на целевой Raspberry. Плагин ещё не опубликован в магазине Volumio. Поиск, «Моя волна», изменение лайков/плейлистов и добавление целого плейлиста пока не реализованы.

## Сборка

На компьютере разработчика нужны Node.js с npm и Python 3.9+:

```bash
npm ci --ignore-scripts --no-audit --no-fund
python3 scripts/build.py
```

Результат: `dist/media_str-0.4.0.zip`. Это ZIP плагина Volumio: `package.json`, `index.js`, `config.json`, `UIConfig.json`, установочные скрипты, Kew и внутренний Python-компонент расположены без внешней папки. Секреты, старый веб-интерфейс и сервис обновлений в пакет не входят.

## Установка для проверки на Volumio

Требования: Volumio 4 / Bookworm, Node.js 14+, Python 3.9+, доступ к интернету для Яндекса. Архитектурно зависимых библиотек нет. Для воспроизведения требуется подходящая подписка Яндекса. Установщик проверяет среду, не обновляет ОС и не меняет настройки аудиовыхода.

1. Скопируйте ZIP на устройство, например:

   ```bash
   scp dist/media_str-0.4.0.zip volumio@volumio.local:/home/volumio/
   ```

2. В SSH-сессии **на Volumio**, от пользователя `volumio`, распакуйте пакет в новый пустой каталог:

   ```bash
   mkdir ~/media-str-plugin-0.4.0
   cd ~/media-str-plugin-0.4.0
   unzip ~/media_str-0.4.0.zip
   volumio plugin install
   ```

3. Откройте **Плагины → Установленные → Яндекс Музыка · Media Str**, включите плагин и откройте настройки.
4. Вставьте OAuth-токен без префикса `OAuth`, нажмите **Войти по токену**, затем **Проверить аккаунт**.
5. В **Обзоре** откройте источник, выберите «Мне нравится» или свой плейлист. Меню трека позволяет добавить его в общую очередь Volumio.

Это процедура разработки через [штатную CLI Volumio](https://developers.volumio.com/plugins/writing-a-plugin). Для публичного распространения после проверки потребуется публикация в магазине. Просто копировать папку в `/data/plugins` или редактировать `plugins.json` не нужно.

Существующий скрипт получения токена сохранён: [инструкция](docs/standalone.md#получить-токен-через-подтверждение-в-браузере), [скрипт](scripts/get_yandex_token.py). Полученный токен вставляется в настройки нового плагина.

## Переход с отдельного сервиса 0.3

Установка нового плагина не останавливает старый сервис и не изменяет его данные. При желании вместо повторного ввода токена выполните из клона репозитория на Volumio:

```bash
sudo python3 scripts/migrate-account.py
```

Скрипт копирует аккаунт из `/var/lib/media-str/app-data/yandex-account.json` в `/data/configuration/music_service/media_str/yandex-account.json` с правами `0600`, владельцем `volumio`. Существующий аккаунт плагина не перезаписывается; содержимое токена не выводится. Переносите аккаунт до входа в новом плагине, при отключённом плагине.

После проверки библиотеки и звука в новом плагине отключите старый автозапуск:

```bash
sudo systemctl disable --now media-str.service
```

Старые `/opt/media-str` и `/var/lib/media-str` сохраняются для возврата. Для возврата отключите новый плагин в Volumio и выполните `sudo systemctl enable --now media-str.service`. Автоматическое удаление старой установки не выполняется.

## Обновление и удаление

Обновляйте весь плагин через механизм Volumio. Для неопубликованной сборки используйте новую версию ZIP и ту же процедуру установки через `volumio plugin install`, предварительно отключив плагин. Сохраняйте предыдущий ZIP и резервную копию каталога настроек вне каталога плагина. Поведение обновления и сохранения конфигурации нужно подтвердить на вашей сборке Volumio перед использованием с единственной копией аккаунта.

Отключение останавливает Python-компонент и убирает источник из «Обзора». Удаление выполняется из менеджера плагинов Volumio; сохранность настроек при удалении не гарантируется. Плагин не устанавливает системные службы, правила sudo или отдельный веб-сервер.

Старые ZIP `media-str-*` и обновления через порт 8099 относятся только к прототипу и **не обновляют новый плагин**. Документация прототипа сохранена в [docs/standalone.md](docs/standalone.md); его сборка теперь выполняется с `--standalone`, установщик — `scripts/install-standalone.sh`.

## Архитектура и данные

```text
Volumio → index.js (music_service/media_str)
             ├── Browse / настройки / очередь
             ├── MPD → выбранный аудиовыход Volumio
             └── Python bridge (stdin/stdout) → API Яндекс Музыки
```

Python запускается при включении плагина от пользователя Volumio и завершается при отключении. При завершении процесса Volumio закрывается канал stdin, и компонент тоже выходит. Сетевой порт для взаимодействия не нужен. Сбой компонента отклоняет ожидающие запросы и убирает источник; повторное включение запускает его заново.

Аккаунт хранится в каталоге настроек плагина `/data/configuration/music_service/media_str/`, отдельно от обновляемого кода. Поле токена в настройках всегда пустое: сохранённое значение не возвращается в интерфейс. Логи плагина не содержат токенов или MP3-ссылок; внутренние журналы самого MPD/Volumio могут содержать адрес воспроизводимого файла.

Kew включён в пакет для совместимости с promises Volumio. `app/app.py` содержит повторно используемую логику Яндекса; `python/bridge.py` импортирует её без запуска старого HTTP-сервера. `service/` и `app/web/` пока сохранены для поддержки и тестирования прототипа, но новый плагин их не запускает.

## Проверка и диагностика

```bash
npm test
python3 -m unittest discover -s tests -v
python3 scripts/build.py
```

Node-тесты требуют Node.js 18+. Сам плагин рассчитан на Node.js 14+. Проверки используют фиктивные ответы Яндекса и Volumio, не выполняют операции с настоящей коллекцией.

На устройстве журнал доступен через `sudo journalctl -u volumio -n 100 --no-pager`. Если источник исчез после ошибки, выключите и включите плагин; проверьте Python, подключение к интернету и аккаунт в настройках.

Проверка на устройстве перед следующим этапом:

- Установка ZIP, включение/отключение без дублирования источника и оставшихся процессов.
- Вход, перезапуск Volumio и сохранение аккаунта; выход без раскрытия токена в UI.
- «Мне нравится», свои плейлисты, следующая/предыдущая страница, недоступные треки.
- Добавление двух треков в очередь, запуск, пауза, перемотка, следующий трек и автоматический переход.
- Смена источника, отключение во время запроса, обновление ZIP и удаление.
- Работа сенсорного экрана и телефона с одним плеером; звук через выбранный ЦАП.
